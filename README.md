TR- # 🎵 LYRA - Akıllı Müzik Tanıma Asistanı

LYRA, bilgisayarınızdaki sistem seslerini veya mikrofonunuzu dinleyerek çalan şarkıları Shazam altyapısıyla bulan minimalist bir masaüstü uygulamasıdır.

## ✨ Özellikler
* Çift Kaynak Desteği (PC Sesi / Mikrofon)
* HUD Mini Pencere Bildirimi
* Dinamik Albüm Rengi Teması
* Geçmiş Arşivi (İçe/Dışa Aktarma)
* Dinleme İstatistikleri Paneli
* Discord Rich Presence Entegrasyonu

## 🚀 Kurulum
1. Gerekli kütüphaneleri yükleyin: `pip install -r requirements.txt`
2. Uygulamayı çalıştırın: `python lyra_app.py`

EN- # 🎵 LYRA - Smart Music Recognition Assistant

LYRA is a minimalist desktop application that identifies currently playing songs by listening to your computer's system audio or microphone, powered by the Shazam engine.

## ✨ Features
* Dual Source Support (PC Audio / Microphone)
* HUD Mini-Window Notifications
* Dynamic Album Color Theme
* History Archive (Import/Export)
* Listening Statistics Dashboard
* Discord Rich Presence Integration

## 🚀 Installation
1. Install the required libraries: `pip install -r requirements.txt`
2. Run the application: `python lyra_app.py`
