# 🎵 LYRA - Müzik Tanıma ve Asistan Sistemi

LYRA, bilgisayarınızda çalan sesleri veya ortamdaki müzikleri Shazam altyapısı kullanarak anında bulan, şarkı sözlerini getiren ve dinleme istatistikleri sunan modern bir masaüstü asistanıdır.

## ✨ Özellikler
* **Bilgisayar Sesi Algılama:** Sistemde çalan müzikleri dahili olarak yakalar.
* **Ortam Mikrofonu:** Çevredeki müzikleri mikrofon aracılığıyla tanır.
* **Anlık Şarkı Sözleri:** Bulunan şarkıların sözlerini `lrclib.net` üzerinden otomatik getirir.
* **30 Saniye Önizleme:** Şarkıların önizleme seslerini dinleme imkanı.
* **Klavye Kısayolları:** 
  * `Ctrl + Shift + P` -> Bilgisayar Sesi Dinle
  * `Ctrl + Shift + M` -> Mikrofonu Dinle
* **Çoklu Dil Desteği:** Türkçe ve İngilizce arayüz seçeneği.

## 🚀 Kurulum
